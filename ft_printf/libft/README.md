# Libft

## Description
**Libft** is the first project of the curriculum. In this project the goal to remake a part of the standard C library functions, and other functions. These functions form a base library, that will be useful in future projects

By making the functions yourself instead of using the already made libraries, you get a better understanding of the core of C. Which will hopefully make it easier to write your own functions later on.

---

## Instructions

### Compilation
The project has a `Makefile` to make compiling easier. The available commands are:

*   `make` - Compiles the library functions and Creates `libft.a`.
*   `make clean` - Deletes all object files (`.o`).
*   `make fclean` - Deletes all object files and the library file (`libft.a`).
*   `make re` - Recompiles the entire project.

### Technical Integration
To  be able to use the library in another C project, you have to include the header file in your code:
```c
#include "libft.h"
```

When compiling your project, link the compiled library file:
```bash
cc main.c -L. -lft -o my_program
```

## Library Features

The library consists of three parts:

### 1. Libc Functions
These are copies of the standard C library functions, strictly following their definitions as in the man page:
*   **Character Checks:** `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint`.
*   **Character Case Conversion:** `ft_toupper`, `ft_tolower`.
*   **String Manipulation:** 
    *   `ft_strlen` - Calculates string length.
    *   `ft_strchr`, `ft_strrchr` - Locates a character in a string.
    *   `ft_strncmp` - Compares two strings up to a specific length.
    *   `ft_strnstr` - Locates a substring within a string.
    *   `ft_strlcpy`, `ft_strlcat` - Size-bounded string copying and concatenation.
*   **Memory Management:**
    *   `ft_memset` - Fills memory with a constant byte.
    *   `ft_bzero` - Zeroes a memory block.
    *   `ft_memcpy`, `ft_memmove` - Copies memory areas.
    *   `ft_memchr`, `ft_memcmp` - Locates and compares bytes in memory blocks.
*   **Allocation & Conversion:**
    *   `ft_atoi` - Converts a string to an integer.
    *   `ft_calloc` - Allocates memory and initializes bytes to zero.
    *   `ft_strdup` - Creates a duplicate of a string using dynamic allocation.

### 2. Additional Functions
These functions are not included in libc, or exist in a different form:
*   `ft_substr` - Gets a substring from a string.
*   `ft_strjoin` - Concatenates two strings into a new allocated third string.
*   `ft_strtrim` - Trims specified characters from the beginning and end of a string.
*   `ft_split` - Splits a string into an array of strings using a specified delimiter.
*   `ft_itoa` - Converts an integer into a string.
*   `ft_strmapi` / `ft_striteri` - Applies a custom function to each character of a string.
*   `ft_putchar_fd` / `ft_putstr_fd` / `ft_putendl_fd` / `ft_putnbr_fd` - Outputs characters, strings, or numbers to a specific file descriptor.

### 3. linked Lists
Functions to work with single-linked lists:
*   `ft_lstnew` - Allocates a new list node.
*   `ft_lstadd_front` / `ft_lstadd_back` - Puts an node at the beginning or end of a list.
*   `ft_lstsize` - Counts the amount of nodes in a list.
*   `ft_lstlast` - Gets the final node of a list.
*   `ft_lstdelone` / `ft_lstclear` - Deletes specific nodes or clears entire lists safely.
*   `ft_lstiter` / `ft_lstmap` - Iterates over nodes to apply or transform data within the list.
